# Cuida Vicenciano

Aplicação web em português para moradores registrarem problemas urbanos e acompanharem o atendimento da prefeitura.

## Desenvolvimento

Para executar o projeto localmente, você precisa do Node.js e do npm. Caso necessário, [instale o Node.js com o nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Tecnologias

- TanStack Start
- TypeScript
- React
- Tailwind CSS
